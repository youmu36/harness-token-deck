# Harness Token Deck

面向多 Harness、多供应商用户的 Windows 本地 Token 用量、费用与钱包仪表盘。

如果你同时使用几家 New API、sub2api 或其他第三方网关，经常需要核对不同模型的计费倍率、剩余余额和消费情况，Harness Token Deck 可以把这些信息放在一个地方查看：从本机 Harness 记录汇总用量，按各供应商的价格估算费用，再与远程账户提供的余额和消费依据对照。

项目仍在开发中，目标是支持更多 Harness。目前已支持 **Claude Code、Codex、Zcode 和 Deepseek Harness（DSH）**。应用按 [MIT 许可证](LICENSE) 开源，数据保存在本机。

## 可以做什么

### 查看不同 Harness 和模型的用量

每个 Harness 都有独立页面，可以查看输入、输出、缓存命中、总 Token 和本地估算费用。常用时间范围包括今天、最近 24 小时、近 7 天和近 30 天，也可选择自定义区间。统计页汇总多个来源，分析页按模型查看长期排名、比较和输出速度趋势，方便了解用量主要花在哪里。

### 为不同供应商设置价格和倍率

先在模型池保存基准价格，再为供应商创建价格组。同一价格组内可保存多套倍率版本，例如“0.8 倍”和“1.2 倍”，并为单个模型按倍率填充或直接填写实际价格。各 Harness 可以选择当前使用的价格组与版本。

价格调整会保留修订记录，已入账费用不会自动改变。需要纠正历史费用时，可以先预览重算结果再确认；遗漏价格的请求也能在“未定价模型相关”页面补价。

### 分开管理本地钱包和远程钱包

本地钱包按你填写的充值和本地估算消费记账；供应商可关联多个价格组，也可补充使用本软件之前的充值与消费总额。资金流水支持备注和人工校准，记账本按月查看已结日账。

远程钱包可连接 **New API、sub2api 或 DeepSeek 官方**的余额接口。接口提供累计消费时，应用优先采用该字段；只提供余额时，则结合本地估算推算区间消费。两种钱包分别保存，便于核对本地估算与供应商账面数据。其他第三方网关仍可使用本地记账，远程连接取决于其接口兼容性。

### 观察会话缓存和输出速度

近期缓存图可以查看命中率变化，并提示达到条件的缓存击穿、大量未命中以及来源明确标记的上下文压缩。多个并行会话的缓存命中率可分别查看。

TPS 同样按会话和模型区分，同一模型开多个对话也不会混算。紧凑框显示会话、近期 tps 与监测状态，下拉以两行卡片显示模型、开始时间、近期 tps 和会话平均 tps。近期值沿用最近三个有效输出分钟的计算方式；会话平均值累计整段对话的有效输出与耗时，用于每日趋势分析。静默十分钟后冻结显示，继续同一对话时接着累计。

TPS 包含思考输出。来源缺少可靠计时，或网络与日志缓冲影响记录时，速度只能作为估算参考。

### 在本机保存历史与备份

统计可组合筛选供应商、来源、时间、价格组与倍率版本，比较缓存、模型吞吐及历史 Token / $1；缺失记录独立保存，可确认后关闭重复提醒。历史数据逐步汇总为日/月维度，较早的用量总额、金额和日账继续保留。设置中可备份数据、导入旧版数据、调整细粒度历史的保留期限。关闭窗口后默认留在托盘继续采集，也可选择开机启动。

## 安装

支持 **Windows 10/11 x64**，需要 Microsoft Edge WebView2 Runtime；缺少运行时时，安装器会引导下载微软官方运行时。

从 [Releases 页面](https://github.com/youmu36/harness-token-deck/releases/latest)下载已发布安装包。安装包包含应用依赖，日常使用无需安装 Python、Node.js 或其他开发工具，也不需要登录 GitHub。若尚无发布版本，可参考[源码构建说明](CONTRIBUTING.md#构建安装包)。

## 初次配置

先到“设置 → 采集来源”确认 Harness 路径，再按应用内的五步指引配置：

1. **模型池**：添加模型并保存输入、输出、缓存命中、缓存创建的基准价格，单位为 USD / 百万 Token。
2. **价格组**：建议按供应商命名，区分不同站点的价格方案。
3. **倍率版本**：使用默认版本或新增版本，建议按实际计费倍率命名。
4. **价格编辑**：添加模型，填写实际价格或按倍率填充，保存后为 Harness 选择对应价格组与版本。
5. **供应商与钱包**：创建供应商并关联价格组，按需补充过往金额或配置远程账户。

New API 需要供应商网站“**个人资料 → 安全 → 访问令牌**”中生成的访问令牌及用户 ID；sub2api 使用该供应商账户下的任意 API 密钥。保存远程账户前可先测试连接。远程钱包反映接口所提供的账面信息，账户余额、单个 Key 的消费和套餐额度可能属于不同口径。

应用内的“设置 → 指南与关于”可随时重新打开使用指南，其中也保留了补价等日常操作说明。本轮新增功能与调整见[当前更新说明](CHANGELOG.md)。

## 数据与隐私

默认从用户目录内的 `.claude`、`.codex`、`.zcode` 和 `.dsh` 发现支持的用量记录，只读来源，不向其中写入内容。应用数据默认保存在 `%LOCALAPPDATA%\HarnessTokenDeck`。

应用没有云同步或多用户服务。只有配置远程账户后，才会访问你选择的站点接口；安装 WebView2 时会访问微软下载服务。远程密钥保存在 Windows 凭据管理器中。

本地费用取决于来源记录是否完整，以及配置的价格是否正确。远程账单也受供应商接口能力限制。备份、日志和问题报告可能包含账户标识、站点或个人用量，请按私人文件保管，提交问题前参阅[安全与隐私说明](SECURITY.md)。
